HOTEL RESERVATION MANAGEMENT SYSTEM - PORTABLE EDITION

This edition uses SQLite. MySQL Server, MySQL Workbench, a MySQL username and a password are NOT required to run the desktop application.

START:
1. Install Python 3.10 or newer.
2. Double-click Start_HotelDB.bat.
3. On first launch, the application creates data/hotel_reservation.db automatically.

The launcher installs tkcalendar if it is not already installed.

DATA:
The database file is data/hotel_reservation.db. Copy this file to the same folder on another computer to move the records. Each computer otherwise has its own local database; this version does not synchronize multiple computers live.

The original MySQL SQL scripts remain in database/ as reference material. The running application uses SQLite.
